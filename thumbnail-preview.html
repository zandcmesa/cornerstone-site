How this works: Each sermon gets a hand-curated imageQuery field — a Wikipedia article name derived from the title. On load, the page fetches the article's lead image from the Wikipedia REST API (no key required, CORS-enabled). Images fade in; the gradient placeholder shows while they load.

Production path: Swap Wikipedia for the Unsplash API (free tier, 50 req/hr). Unsplash gives higher-quality editorial photography and a larger search space. Requires a free access key.
